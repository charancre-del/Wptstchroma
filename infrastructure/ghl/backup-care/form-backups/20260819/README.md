# GHL Form Snapshots

These files are immutable evidence of the forms read back on August 19, 2026. They are not deployment inputs.

`booking-terms-v1.json` is a legacy unsafe form contract and must be archived or disabled in GHL before launch. It is intentionally retained for audit and rollback evidence. Public code exposes only the Family Profile and Child Enrollment forms; payment and order state are written only by the WordPress coordinator after a verified Stripe event.
